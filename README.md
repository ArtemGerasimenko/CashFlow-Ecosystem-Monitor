# CashFlow Ecosystem Monitor

Node.js 20+ приложение: веб-интерфейс, серверный API, опрос публичного рынка XT и история ответов.

## Запуск

1. Распакуйте архив полностью, сохранив структуру папок.
2. Установите Node.js версии 20 или новее.
3. В корневой папке проекта выполните `npm start`.
4. Откройте в браузере `http://localhost:8080`. На телефоне используйте адрес компьютера/сервера в локальной сети или опубликованный HTTPS-адрес.

**Не открывайте `public/index.html` как отдельный файл.** Страница обращается к серверным маршрутам `/api/...`; при прямом открытии без Node.js API не работает. Стили и скрипты подключены относительными путями, чтобы корректно загружаться из каталога `public`.

## Настройки

Скопируйте `.env.example` в `.env` при использовании загрузчика переменных окружения (или задайте переменные окружения в хостинге):

- `PORT` — порт сервера (по умолчанию 8080)
- `POLL_INTERVAL_MS` — интервал опроса (минимум 15000 мс, по умолчанию 60000)
- `HISTORY_RETENTION_DAYS` — срок хранения истории; 0 означает без автоматического удаления
- `XT_BASE_URL` — по умолчанию `https://sapi.xt.com`
- `XT_SYMBOL` — торговая пара, по умолчанию `btc_usdt`

Зависимостей npm нет: используются встроенные модули Node.js. Сервер автоматически создаёт `data/monitor-history.json`.

## API приложения

- `GET /api/health` — проверка доступности
- `GET /api/status` — последний статус источников
- `GET /api/history` — история опросов
- `GET /api/refresh` — принудительный опрос источников

## Подключённые источники и ограничения

- **XT:** публичные spot-эндпоинты ticker/24h и depth; только рыночные данные. В проекте нет доступа к балансу, ордерам, депозитам или выводу средств. Документация: https://doc.xt.com/docs/spot/Market/GetBestPendingOrderTicker и https://doc.xt.com/
- **BlackBit, Money Storage, Winance:** помечены как `not_configured`. Их API нельзя честно включить без подтверждённых официальных адресов, документации и, если требуется, выданных владельцем ключей. Никакие фиктивные значения не подставляются.

## Калькулятор вывода

Используется согласованное правило: фиксированная комиссия 3 USDT плюс 1% от суммы, которую пользователь должен получить. Минимум проверяется по чистой сумме после обеих комиссий — не менее 10 USDT. Формула для суммы до комиссии: `gross = net * 1.01 + 3`. Для доступной суммы `gross`: `net = max(0, (gross - 3) / 1.01)`. Например, 13.10 USDT до вывода дают 10.00 USDT на руки.

Остальные тарифы маршрута намеренно не включены до проверки актуальной тарифной таблицы.

## Безопасность

- Не добавляйте секретные ключи в HTML/JavaScript или Git.
- Публичные рыночные данные XT не требуют приватного ключа.
- Этот проект не совершает сделки и не отправляет выводы.
- Перед публичным развёртыванием добавьте HTTPS, ограничение доступа к истории и защиту от частых ручных refresh-запросов.
