# CashFlow Ecosystem Monitor — API edition

## Что реально реализовано
- Node.js 20+ backend; API-ключи и адреса источников остаются на сервере.
- `/api/health`, `/api/status`, `/api/history`, `/api/refresh`.
- Плановое обновление раз в 60 секунд (настраивается `POLL_INTERVAL_MS`).
- XT public market adapter: best 24h ticker + public depth.
- Постоянная JSON-история на диске в `data/monitor-history.json` (без очистки по умолчанию).
- UI для статусов источников, XT данных, истории и калькулятор комиссии вывода.
- Комиссия вывода: 3 USDT + 1% от net amount; минимум 10 USDT чистыми.

## Что пока не подключено
BlackBit, Money Storage и Winance явно возвращают `not_configured`. Это намеренно: нет подтверждённых официальных API-контрактов/учётных данных в предоставленных материалах. Не вводите вымышленные URL, комиссии или тарифы. Для реального подключения нужны официальная документация API, base URL, методы авторизации и разрешённые endpoints от каждой площадки.

XT подключён только к публичным рыночным данным. Балансы, депозиты, выводы и торговые операции XT не реализованы; для приватных операций потребуются API key/secret и отдельное подтверждение требований безопасности.

## Установка
1. Установить Node.js 20 или новее.
2. Скопировать `.env.example` в `.env` при необходимости.
3. `npm start`
4. Открыть `http://localhost:8080`.

## Развёртывание
Разместить на Node.js-хостинге (например, Railway). Указать `PORT` автоматически либо `8080`. Секреты задавать только в Variables/Secrets хостинга, никогда не в `public/` и не в GitHub Pages.

## API
- `GET /api/health`
- `GET /api/status`
- `GET /api/history`
- `GET /api/refresh`

## Важно
Исторические данные хранятся в `data/monitor-history.json`. Для нескольких инстансов или высокой нагрузки заменить JSON store на PostgreSQL. Для production добавить авторизацию административных настроек, audit log, backup и мониторинг ошибок.
