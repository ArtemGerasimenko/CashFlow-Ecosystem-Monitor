# CashFlow Ecosystem Monitor

Отдельный адаптивный веб-модуль на основе доступного скриншота меню BB Monitor.

## Состав
- Обзор
- Курсы ECR / ECT / eRUB (ожидают подтверждённые API)
- Стакан и история (ожидают API)
- Где дешевле купить eRUB (ожидает API и комиссии)
- Калькулятор Money Storage → ECR → BB → USDT с редактируемыми параметрами
- Ручное сравнение курса с биржей
- Статус XT (ожидает API)
- Обратная связь (локальное копирование сообщения)

## Запуск
Открой `index.html` в браузере или опубликуй репозиторий через GitHub Pages.

## Важно
Это первая реализация по одному скриншоту, не полная копия закрытой логики @blackbit_monitor_bot.
Значения калькулятора по умолчанию взяты/выведены из присланного примера и должны быть проверены:
- 108 EUR, курс покупки 9.7 EUR/ECR
- комиссии покупки 0.5%, перевода 0.5%, продажи 0.1%
- комиссия вывода 3.05 USDT, минимум 13.31 USDT
- курс продажи в примере рассчитан обратно из показанных 7.9409 USDT; это демонстрационное значение, не live-курс.

Рыночные курсы, стакан, история, уведомления и статус XT не имитируются: для них требуются подтверждённые API-источники и серверная часть. Не публикуйте секретные API-ключи в GitHub Pages.
