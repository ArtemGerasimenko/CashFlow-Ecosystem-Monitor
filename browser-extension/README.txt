УСТАНОВКА РАСШИРЕНИЯ CASHFLOW BLACKBIT LIMIT OBSERVER

1. Запустите CashFlow Monitor локально на компьютере, на порту 8080.
2. Откройте Chrome и перейдите на chrome://extensions
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите эту папку browser-extension.
6. Откройте BlackBit в той же версии Chrome и войдите обычным способом.
7. Вручную откройте форму вывода и нажмите кнопку проверки/вывода, как обычно.
8. НЕ подтверждайте транзакцию. Расширение только считывает видимое уведомление:
   «Максимальная сумма для вывода ... USDT».
9. Откройте CashFlow Monitor и обновите раздел «Расчёт вывода».
   Максимум BlackBit появится со статусом «Браузер · считано».

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ
- Расширение не нажимает кнопки и не отправляет заявку на вывод.
- Не читает пароли, API-ключи, cookies, localStorage или поля ввода.
- Считывает только видимый текст уведомления на странице BlackBit.
- Передаёт только число максимума в локальный CashFlow Monitor на 127.0.0.1:8080.
- Автоматически считывает лимит только после того, как уведомление появилось на странице.
- Это локальный браузерный наблюдатель, а не официальный API биржи.
- Для Winance наблюдатель пока не создан: нужен такой же видимый текст/экран от Winance.
- Если CashFlow запущен не на localhost:8080, нужно будет изменить URL в service-worker.js и host_permissions в manifest.json.
